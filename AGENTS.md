# Diretrizes para Agentes Autônomos de IA (AGENTS.md)

Este repositório adota as instruções técnicas detalhadas descritas em [`CLAUDE.md`](CLAUDE.md).

Para qualquer tarefa de execução, manutenção, refatoração de código em R ou expansão do banco de dados relacional e auditoria do PELD, consulte o arquivo [`CLAUDE.md`](CLAUDE.md) para compreender:
- A arquitetura do pipeline e a ordem sequencial dos scripts;
- Os caminhos fixos dos interpretadores R e bibliotecas do usuário no Windows;
- As convenções do esquema relacional SQLite e do dicionário de mapeamento;
- As armadilhas metodológicas detectadas (efeito de escala, falácia ecológica e dados oportunistas).
